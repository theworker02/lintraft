# lintraft

Lint numeric raft values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/lintraft/

## Install / run

```bash
git clone https://github.com/theworker02/lintraft.git
cd lintraft
node src/cli.js
node --test
```
